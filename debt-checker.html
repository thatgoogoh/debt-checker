ไถ่เชียงกรุ๊ป

⚙️ วิธีตั้งค่าครั้งแรก (คลิกเพื่อดู)
1
ไปที่ Google Cloud Console → สร้าง Project ใหม่
2
เปิด APIs & Services → Library → ค้นหา Google Drive API → Enable
3
ไปที่ APIs & Services → OAuth consent screen → เลือก External → กรอกชื่อแอป → Save
4
ไปที่ Credentials → Create Credentials → OAuth 2.0 Client ID → เลือก Web application
ใส่ Authorized JavaScript origins: https://thatgoogoh.github.io
5
คัดลอก Client ID ที่ได้ → เปิดไฟล์ debt-checker.html → หาบรรทัด GOOGLE_CLIENT_ID → วางแทน
6
สร้างโฟลเดอร์ชื่อ claude ใน Google Drive → วางไฟล์ Excel ทั้ง 4 บริษัทตามชื่อที่กำหนด
7
Push ไฟล์ขึ้น GitHub → เปิดจาก GitHub Pages → กด "เชื่อมต่อ Google" ✅
